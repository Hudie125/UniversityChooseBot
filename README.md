**UniversityChooseBot** — интеллектуальный Telegram-бот, помогающий школьникам, студентам и абитуриентам выбрать оптимальную страну для учёбы, специальность и университет с учётом их интересов, оценок, экзаменов, портфолио, бюджета и личных пожеланий.

Бот объединяет интерактивную 9-шаговую анкету с машиной состояний (FSM) и **бесплатную облачную нейросеть**, формирующую персональный отчёт с подбором программ, стратегией подготовки к экзаменам, советами по стипендиям и возможностью задавать уточняющие вопросы в режиме живого диалога.

---

## 🌟 Основные возможности

- 📋 **Интерактивная анкета из 9 вопросов:**
  1. *Текущий этап образования* (школа, колледж, вуз, др.).
  2. *Планируемый срок поступления* (в ближайший год, через 2 года, пока не определился).
  3. *Интересующие направления* — удобный множественный выбор (чекбоксы `✅`/`⬜` с кнопкой `👉 Готово` и взаимным исключением для варианта *«Пока не знаю»*).
  4. *Предпочтительные страны и регионы* (Россия, Европа, Азия, Северная Америка и др.).
  5. *Язык обучения* (русский, английский, местный язык с подготовкой).
  6. *Бюджет на обучение* (с акцентом на стоимость обучения без проживания).
  7. *Экзамены и текущие/ожидаемые баллы* (свободный текст + быстрая кнопка).
  8. *Личные достижения и портфолио* (олимпиады, проекты, волонтерство + быстрая кнопка).
  9. *Дополнительные пожелания и ограничения* (стипендии, работа во время учебы, общежитие).

- 🧭 **Удобная навигация и защита данных:**
  - Кнопка **«◀️ Назад»** на каждом шаге позволяет вернуться и скорректировать ответ без потери остальных данных.
  - Кнопка **«❌ Отменить анкету»** и команда `/cancel` для сброса.
  - Динамическое обновление клавиатур через `edit_text` / `edit_reply_markup` без захламления чата.
  - Безопасное экранирование HTML (`<`, `>`, `&`), защищающее от сбоев Telegram API.

- 🤖 **Интеграция с онлайн-нейросетью:**
  - Бесплатный облачный AI (не нагружает компьютер пользователя).
  - Персонализированный отчёт: анализ профиля, топ-3-5 вузов, языковые требования, гранты/стипендии и пошаговый план на 3–6 месяцев.
  - **Интерактивный диалог с ИИ:** после получения рекомендаций можно нажать *«💬 Задать вопрос ИИ-консультанту»* и задавать любые уточняющие вопросы (по визам, стипендиям, дедлайнам).

## 🏗 Архитектура проекта

```text
UniversityChooseBot/
├── bot.py                # Точка входа, настройка логирования UTF-8, инициализация и graceful shutdown
├── handlers.py           # Роутеры команд (/start, /cancel), шагов анкеты, кнопок и диалога с ИИ
├── questionnaire.py      # FSM-состояния (StatesGroup), тексты, клавиатуры и генератор резюме
├── ai_service.py         # Модуль интеграции с бесплатной облачной нейросетью
├── requirements.txt      # Зависимости проекта
├── .env.example          # Пример конфигурационного файла
├── .gitignore            # Исключение виртуального окружения, секретов и кэша
├── pytest.ini            # Конфигурация для запуска автоматических тестов
└── tests/                # Набор модульных и интеграционных тестов
    ├── test_questionnaire.py  # Тесты клавиатур, логики и резюме
    └── test_fsm_flow.py       # Тесты цепочки FSM, возврата назад и отмены
```

## 🚀 Быстрый старт (Windows PowerShell)

### 1. Клонирование репозитория

```powershell
git clone https://github.com/Hudie125/UniversityChooseBot.git
cd UniversityChooseBot
```

### 2. Создание и активация виртуального окружения

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

> 💡 *Если PowerShell блокирует запуск скриптов, выполните:*
> `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`

### 3. Установка зависимостей

```powershell
pip install -r requirements.txt
pip install pytest pytest-asyncio
```

### 4. Настройка конфигурации (.env)

Создайте файл `.env` на основе примера:
```powershell
Copy-Item .env.example .env
notepad .env
```

Укажите в `.env` токен вашего бота, полученный у [@BotFather](https://t.me/BotFather):
```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz

# Опционально: локальный прокси (например, vpGram / Xray)
PROXY_URL=socks5://127.0.0.1:17808
```

### 5. Запуск тестов

```powershell
pytest
```
*Все 13 тестов должны успешно пройти (`13 passed`).*

### 6. Запуск Telegram-бота

```powershell
python bot.py
```

Откройте вашего бота в Telegram и отправьте команду `/start`!

## 🧪 Автоматическое тестирование

Проект покрыт автоматическими тестами `pytest`:
- Корректность списков направлений, стран, языков и бюджетов.
- Работа одиночного и множественного выбора (добавление, удаление, исключение варианта «Пока не знаю»).
- Сохранение ответов при шаге назад («◀️ Назад»).
- Сброс состояний при отмене (`/cancel`).
- Безопасное экранирование специальных символов HTML в итоговом резюме.
